# stages — 단계별 작업

단계마다 **자기완결적인 지시서**를 설계 세션이 쓰고, 실행 세션이 그 지시서대로 실행한다. 한 단계는 한 세션에서 끝낸다.

## 지시서와 실행 위치

| 순서 | 지시서 | 내용 | 실행 위치 | 외부 접속 |
|---|---|---|---|---|
| 1 | {{`S1_NAME_INSTRUCTIONS.md`}} | | {{설계 / 로컬 Claude Code / 서버}} | {{없음 / 읽기 전용 DB}} |

## 공통 규칙 (모든 지시서에 적용)

1. `CLAUDE.md` 절대 규칙을 따른다.
2. 종결된 단계의 코드·산출물은 고치지 않는다. import하거나 로직을 옮겨 쓴다.
3. 지시서의 정의·문턱·시드는 **결과를 본 뒤 바꾸지 않는다.** 막히면 멈추고 "판단 필요"로 보고한다.
4. 판정 문장("그러니 이렇게 하자")은 쓰지 않는다. 범주는 지시서의 기계적 규칙으로만 붙인다.
5. {{프로젝트 공통 규칙 추가}}

## 디렉터리

```
stages/
  README.md                          이 문서 (단계 목록, 공통 규칙)
  TEMPLATE_INSTRUCTIONS.md           지시서 뼈대 (복사해서 쓴다)
  S1_NAME_INSTRUCTIONS.md            단계 지시서 (설계 세션이 작성)
  s1/                                단계 코드(*.py)와 outputs/(표·그림·json)
  s1/data/                           재생성 가능한 캐시 (git 제외)
```

지시서 파일은 `stages/` 바로 아래, 코드·산출물은 단계별 하위 폴더에 둔다.
