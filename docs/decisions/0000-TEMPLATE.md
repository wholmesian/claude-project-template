# NNNN. 결정을 한 문장으로 (동사로 끝낸다)

- 상태: **제안** (`제안` / `확정` / `확정(임시)` / `대체됨(→ NNNN)`)
- 날짜: YYYY-MM-DD (확정일. 사용자 확인한 날)
- 대체: (이 ADR이 대체하는 번호. 없으면 줄 삭제)
- 관련: (보고서, 지시서, 커밋, 다른 ADR 링크)

## 배경

무엇이 문제였고, 왜 지금 정해야 했나. 이 맥락을 모르는 사람이 읽는다고 가정하고 3 - 6문장.

## 고려한 대안

| 대안 | 장점 | 단점 | 채택 |
|---|---|---|---|
| A | | | |
| B | | | ○ |

## 결정

- 정한 것을 목록으로. 정의·임계값·범위처럼 나중에 바꾸면 안 되는 값은 여기 값으로 적는다.
- 사용자가 직접 지시·승인한 부분은 "(사용자 지시)"로 표시한다.

## 영향

- 무엇이 달라지나(규칙, 산출물 위치, 이후 단계).
- 이 결정에 기대는 문서·코드.

## 되돌리는 조건

어떤 사실이 드러나면 이 결정을 다시 보나. (없으면 "없음"이 아니라 왜 없는지 한 줄)
